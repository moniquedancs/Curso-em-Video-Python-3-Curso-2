# Curso em Vídeo - Python 3 - Curso 2
Exercícios realizados ao longo do curso de Python 3, curso 2, do Curso em Vídeo. Ressaltando que os exercícios foram realizados antes de verificar a resolução, como incentivado pelo Prof. Gustavo Guanabara. Esse curso já foi finalizado antes que a minha conta do GitHub fosse criada, e os exercícios foram revisados.
Ao todo, foram 35 exercícios. 
EX036 à EX045: condições aninhadas.
EX046 à EX056: estrutura de repetição for. 
EX057 à EX065: estrutura de repetição while.
EX066 à EX071: interrompendo repetições while.
